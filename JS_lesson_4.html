JS_lesson_4: Условия, логика и изменение DOM через JavaScript

ex04 – First If Else

В программировании часто нужно проверять какие-то условия: например, больше ли число 10, равно ли что-то другому, или подходит ли пользователь по возрасту. Для таких проверок в JavaScript используется конструкция if / else.

if переводится как "если", а else — "иначе". Это условная логика: если что-то верно, делай одно, иначе — делай другое.

let nbr = 10;

if (nbr > 20) {
  console.log("nbr is greater than 20");
} else {
  console.log("nbr is less than or equal to 20");
}

Здесь переменная nbr сравнивается с числом 20. Если nbr больше 20 — выполняется код внутри if. Если нет — выполняется else.

Операторы сравнения:

  • > — больше
  • < — меньше
  • == — равно по значению
  • === — строгое равенство (и по типу, и по значению)
  • != — не равно
  • !== — строго не равно
  • >= — больше или равно
  • <= — меньше или равно

Важно: в JavaScript есть разница между == и ===. Например, 5 == "5" даст true, но 5 === "5" даст false, потому что типы разные (число и строка).

ex05 – First If Multiple Conditions

Иногда нужно проверять сразу несколько условий. Например: "если число больше 10 и меньше 20", или "если пользователь — админ или модератор". В таких случаях применяются логические операторы:

Логические операторы:

  • && — логическое "И": обе части должны быть true
  • || — логическое "ИЛИ": хотя бы одна часть должна быть true
  • ! — логическое "НЕ": инвертирует результат

Примеры:

let a = 10, b = 5, c = 15, d = 10;

if (a > b && a < c && a === d) {
  console.log("a is between b and c and equal to d");
}

let x = 10, y = 20, z = 5;

if (z > x || y > x) {
  console.log("z OR y is greater than x");
}

let loggedIn = false;

if (!loggedIn) {
  console.log("Пользователь не вошёл");
}

Таким образом можно строить сложную логику. Например, условие if (userAge > 18 && isMember === true) означает: если возраст больше 18 и пользователь — участник, тогда выполняем код.

ex06 – Change Box Color With JavaScript

На этом шаге мы учимся взаимодействовать с HTML через JavaScript. Это называется DOM (Document Object Model) — модель, которая позволяет JavaScript видеть HTML-страницу как структуру из объектов (дерево элементов).

Каждому HTML-элементу можно дать id, по которому мы его "найдём" из JavaScript:

<div id="my_box"></div>

Как получить доступ к элементу?

let my_box = document.getElementById("my_box");

Как изменить цвет фона элемента?

my_box.style.backgroundColor = "#00FF00"; // зелёный

Можно менять и другие стили:

my_box.style.width = "200px";
my_box.style.height = "100px";
my_box.style.border = "2px solid black";
my_box.style.display = "none"; // скрыть элемент

Полный пример:

<!DOCTYPE html>
<html>
<head>
  <title>Change Box Color</title>
</head>
<body>
  <div id="my_box" style="width:100px; height:100px; background-color:#ff0000;"></div>
  <button onclick="changeColor()">Изменить цвет</button>

  <script>
    function changeColor() {
      let my_box = document.getElementById("my_box");
      my_box.style.backgroundColor = "#00FF00";
    }
  </script>
</body>
</html>

Когда пользователь нажимает кнопку — срабатывает функция changeColor(), которая меняет стиль коробки.

Заключение

  • if/else — управляет логикой на основе условий
  • ==, ===, !=, <, > — операторы сравнения
  • && и || — логика "и"/"или"
  • ! — инвертирует значение
  • DOM — структура страницы, которую можно менять из JS
  • getElementById() — получить HTML-элемент
  • .style — доступ к CSS-стилям элемента
