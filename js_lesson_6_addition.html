Анонимные и стрелочные функции в JavaScript

🔹 Что такое анонимные функции?

Анонимная функция — это функция без имени. Такие функции часто передаются как аргументы в другие функции или сохраняются в переменные. Пример: 

const sayHi = function() {
  console.log("Привет!");
};

Здесь функция не имеет имени и присваивается переменной sayHi.

🔹 Что такое стрелочные функции?

Стрелочные функции (arrow functions) — это современный способ записи функций, появившийся в стандарте ES6. Они выглядят компактно и особенно удобны в коротких функциях и колбэках: 

const sayHi = () => {
  console.log("Привет!");
};

Стрелочная функция отличается тем, что не имеет собственного this и не поддерживает arguments.

📌 Основные отличия между function и стрелочной функцией

Особенность Обычная функция (function) Стрелочная функция (=>)
Собственное this ✅ Есть ❌ Нет
Поддержка arguments ✅ Да ❌ Нет
Можно вызвать с new ✅ Да (конструктор) ❌ Нет
Подходит для методов объектов ✅ Да ⚠️ С осторожностью
Краткость записи ❌ Много кода ✅ Да

🔍 Пример с this в объекте

const user = {
  name: "Анна",
  sayHi: function() {
    console.log("Привет, " + this.name);
  }
};
user.sayHi(); // Привет, Анна
const user = {
  name: "Анна",
  sayHi: () => {
    console.log("Привет, " + this.name);
  }
};
user.sayHi(); // Привет, undefined ❌
Стрелочная функция не создаёт своего this, поэтому this.name не указывает на объект user.

✅ Когда использовать какую функцию?

  • Обычную функцию (function): использовать для методов объектов, конструкций с this или arguments.
  • Стрелочную функцию (=>): использовать для коротких выражений, колбэков, замыканий, особенно если нужно сохранить внешний this.
setTimeout(() => {
  console.log("Задержка 1 секунда");
}, 1000);

📚 Вывод

Стрелочные функции — это удобный синтаксис для коротких операций и функционального программирования. Однако важно понимать их особенности: отсутствие собственного this и невозможность использования как конструктора.

Всегда выбирай тип функции в зависимости от задачи: если нужно работать с контекстом — используй function, если нужна краткость и внешний this — =>.
