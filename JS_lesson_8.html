JS_lesson_8: Переменные, типы и множественные условия

ex01 — Multiple Variables Multiple Type

Переменная — это именованная ячейка, в которой можно хранить данные: текст, числа и многое другое. В JavaScript переменные создаются с помощью let или const.

Типы данных:

  • let age = 34; — число (integer)
  • let name = "Luke"; — строка (string)
  • let comma = ','; — символ, который в JavaScript считается строкой

Тип char как в других языках (C, Java) в JS отсутствует. Один символ — это тоже строка длиной 1.

Конкатенация — объединение строк:

let name = "Luke";
let age = 34;
let comma = ',';

console.log("Hello " + name + comma + " I'm " + age + " years old.");

Это объединит все части в одну строку и выведет:

Hello Luke, I'm 34 years old.

Одинарные и двойные кавычки:

  • Можно использовать оба варианта: 'текст' или "текст"
  • Важно: открывающая и закрывающая кавычки должны быть одинаковыми
  • Лучше придерживаться одного стиля во всём проекте

Почему лучше использовать let или const?

  • Если не использовать — переменная попадёт в глобальную область, что плохо для больших программ
  • let позволяет изменить значение
  • const — переменная, значение которой не меняется

ex02 — First If Multiple Conditions

Условия позволяют выполнять действия, только если соблюдается определённое правило. Сложные условия — это когда нужно проверить несколько правил одновременно.

Операторы сравнения:

  • > — больше
  • < — меньше
  • == — равно по значению
  • === — строгое равенство (тип + значение)

Логические операторы:

  • && — логическое "И": все условия должны быть верны
  • || — логическое "ИЛИ": хотя бы одно условие должно быть верным
  • ! — логическое "НЕ": инвертирует значение

Пример сложного условия:

let a = 10, b = 9, c = 11, d = 10;

if (a > b && a < c && a == d) {
  console.log("a is between b and c and equal to d");
}

Пример с ||:

let a = 10, y = 9, z = 11;

if (z > a || y > a) {
  console.log("z OR y is greater than a");
}

Вложенные условия (if внутри if):

let score = 85;

if (score > 50) {
  if (score >= 80) {
    console.log("Отлично!");
  } else {
    console.log("Хорошо");
  }
} else {
  console.log("Попробуй ещё раз");
}

Это пример вложенной логики: сначала проверяется одно, а затем другое.

Важность скобок:

Чтобы не запутаться в сложных условиях, всегда используй скобки для группировки:

if ((a > b && a < c) || d === a) {
  console.log("Сложное условие");
}

Итоги

  • Объявляй переменные с let или const
  • Используй логичные имена переменных
  • Объединяй строки с помощью +
  • Проверяй условия с if, else, &&, ||
  • Следи за правильным использованием скобок
  • Понимай разницу между == и ===
