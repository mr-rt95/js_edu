JS_lesson_1: JavaScript, переменные и целые числа

1. Что такое HTML, CSS и JavaScript?

HTML — это структура сайта: заголовки, текст, кнопки.

CSS — это оформление сайта: цвета, размеры, отступы.

JavaScript — это логика сайта: делает сайт интерактивным.

2. Что такое переменная?

Переменная — это как коробка с именем. В неё можно положить что-то, например, число 34:

let age = 34;

3. Зачем нужны переменные?

Переменные позволяют хранить данные и использовать их позже. Например:

let name = "Elmar";

4. Как объявлять переменные?

  • let — переменная, которую можно менять
  • const — переменная, которую менять нельзя
  • var — устаревший способ, лучше не использовать

5. Что такое типы данных?

Тип данных — это то, что находится в переменной:

  • Число: 34
  • Строка: "Elmar"
  • Логическое значение: true / false

6. Целые числа (integer)

Integer — это число без запятой, например: 0, 5, -10, 100

let apples = 10;

7. Как использовать переменные?

let age = 18;
console.log(age); // покажет 18

8. Как вывести данные в консоль?

Для вывода используем команду:

console.log(...);

9. Как открыть консоль в браузере?

  • Открыть HTML-файл в браузере
  • Правый клик → Инструменты разработчика
  • Перейти на вкладку "Console"

10. Как вставить JavaScript в HTML?

<script>
  let age = 34;
  console.log("Возраст: " + age);
</script>

11. Частые ошибки новичков

  • Имя переменной не может начинаться с цифры
  • Нельзя использовать пробелы в имени
  • Нужно обязательно использовать let или const

12. Что дальше?

Теперь ты знаешь:

  • Как создавать переменные
  • Как использовать числа
  • Как встроить JavaScript в HTML

13. Итоги

  • HTML — структура
  • CSS — оформление
  • JavaScript — поведение
  • Переменные — хранят данные
  • Integer — целое число
  • console.log — вывод в консоль
  • <script> — вставка кода в HTML
