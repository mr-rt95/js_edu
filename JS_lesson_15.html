JS_lesson_15: Форматирование строк (My String Formatting)

Что такое строка?

Строка (string) — это текст. В JavaScript строка может быть записана:

  • в одинарных кавычках: 'Привет'
  • в двойных кавычках: "Привет"
  • в шаблонных строках (обратные кавычки): `Привет`

Конкатенация строк с числами

Можно соединять текст и числа с помощью знака +:

let name = "Elmar";
let age = 20;
console.log("Меня зовут " + name + ", мне " + age + " лет.");

Шаблонные строки (template literals)

Это современный и удобный способ подставлять значения прямо внутрь строки, используя обратные кавычки (``) и синтаксис ${...}:

let name = "Elmar";
let age = 20;
console.log(`Меня зовут ${name}, мне ${age} лет.`);

Это работает даже с выражениями:

console.log(`Через год мне будет ${age + 1} лет.`);

Форматирование строки с переходом на новую строку

Символ \n создаёт переход на новую строку:

console.log("Привет\nМир!");

Вывод:

Привет
Мир!

Пример: функция форматирования строки

function my_string_formatting(firstname, lastname, age) {
  console.log(`Hello, my name is ${firstname} ${lastname}, I'm ${age}.
`);
}

Вызов:

my_string_formatting("Elmar", "Rahimov", 20);

Результат:

Hello, my name is Elmar Rahimov, I'm 20.

Дополнительно: строковые методы

  • .toUpperCase() — переводит строку в ВЕРХНИЙ РЕГИСТР
  • .toLowerCase() — переводит строку в нижний регистр
  • .length — длина строки

Итоги

  • Строки — текст в кавычках
  • Можно объединять строки с числами с помощью +
  • Шаблонные строки — удобный способ вставки переменных
  • \n — переход на новую строку
  • console.log() — выводит информацию в терминал
  • Функции могут использовать строки и числа вместе
