JS_lesson_12: Модуль числа (функция abs)

Что такое модуль числа?

Модуль числа — это расстояние до нуля. Всегда положительное значение.

  • abs(-5) → 5
  • abs(7) → 7
  • abs(0) → 0

Готовая функция: Math.abs()

В JavaScript есть встроенная функция Math.abs(), которая возвращает модуль числа:

console.log(Math.abs(-3)); // 3
console.log(Math.abs(5));  // 5

Но в этом задании нужно самому реализовать такую функцию без использования Math.abs.

Как вручную вычислить модуль?

Простая логика:

  • Если число < 0 → вернуть -число
  • Иначе → вернуть как есть

Пример:

function my_abs(n) {
  if (n < 0) {
    return -n;
  } else {
    return n;
  }
}

Тесты:

console.log(my_abs(-8)); // 8
console.log(my_abs(4));  // 4
console.log(my_abs(0));  // 0

Что такое тернарный оператор?

Это короткая форма if / else:

условие ? значение_если_true : значение_если_false;

Та же функция с тернарным оператором:

function my_abs(n) {
  return n < 0 ? -n : n;
}

Это означает: если n меньше нуля — вернуть -n, иначе — вернуть n.

Арифметические операции

Чтобы изменить знак числа, мы просто умножаем его на -1:

let x = -10;
console.log(-x); // 10

Сравнение чисел

  • < — меньше
  • > — больше
  • == — равно
  • !== — не равно

Итоги

  • Модуль всегда положительный
  • Можно использовать if / else или тернарный оператор
  • Нельзя использовать Math.abs() в этом задании
  • return — возвращает значение из функции
  • Числа сравниваются с помощью < и других операторов
