JS_lesson_6: Функции, параметры и обратные циклы

ex01 – First Function

Функция — это блок кода, который можно вызвать по имени. Она нужна, чтобы не повторять один и тот же код несколько раз.

Как создать простую функцию:

function my_first_function() {
  console.log("my_first_function");
}

В этом примере:

  • function — ключевое слово, чтобы создать функцию
  • my_first_function — имя функции
  • () — скобки, в которых могут быть параметры
  • { ... } — тело функции, что она будет делать

Как вызвать функцию:

my_first_function(); // Вызывает функцию

Функцию можно вызывать сколько угодно раз:

my_first_function();
my_first_function();

Функции стоит использовать, когда:

  • Нужно повторить одно и то же действие
  • Хочешь сделать код более понятным
  • Хочешь разделить программу на маленькие логические части

ex02 – Function With Params

Функция может принимать параметры — значения, которые передаются при вызове и влияют на поведение функции.

Пример:

function detonation_in(seconds_left) {
  console.log("detonation in... " + seconds_left + " seconds.");
}

Теперь мы можем вызывать эту функцию с разными параметрами:

detonation_in(5); // Вывод: detonation in... 5 seconds.
detonation_in(3); // Вывод: detonation in... 3 seconds.

Параметры функции:

  • seconds_left — это переменная внутри функции
  • Она получает значение, которое мы передаём при вызове
  • Можно передавать числа, строки, даже другие функции

Что такое цикл while в обратном порядке?

Можно сделать цикл, который идёт сверху вниз — от 10 до 1. Это называется обратный отсчёт. Мы используем while и -- (декремент):

let timer = 10;
while (timer > 0) {
  detonation_in(timer);
  timer--;
}

Этот цикл каждый раз уменьшает значение timer и вызывает функцию detonation_in().

Что такое декремент?

Это уменьшение переменной на 1. Записывается как --:

let x = 5;
x--; // теперь x = 4

Также можно писать x -= 1;, результат тот же.

Расширенные варианты

Можно передавать несколько параметров:

function greet(name, time) {
  console.log("Hello " + name + "! It's " + time);
}
greet("Elmar", "morning");

Можно вернуть значение из функции с помощью return:

function add(a, b) {
  return a + b;
}
let result = add(3, 4); // result = 7

Анонимные и стрелочные функции (современный стиль):

const sayHi = () => {
  console.log("Hi!");
};
sayHi();

Итоги

  • function имя() {...} — создаёт функцию
  • имя(); — вызывает функцию
  • function с параметрами — позволяет передавать значения внутрь
  • return — возвращает значение
  • timer-- — уменьшает переменную на 1
  • while (timer > 0) — цикл обратного отсчёта
