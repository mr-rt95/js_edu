JS_lesson_7: Возврат значений и перемещение элементов

ex03 – Function With Return

Функция может не только выполнять действия (например, печатать в консоль), но и возвращать значение наружу с помощью ключевого слова return.

Пример:

function my_get_seven() {
  return 7;
}
console.log(my_get_seven()); // выведет 7

Что делает return:

  • Останавливает выполнение функции
  • Возвращает результат, который можно сохранить или использовать дальше

Пример с переменной:

function multiplyByTwo(x) {
  return x * 2;
}

let result = multiplyByTwo(5); // result = 10
console.log(result);

Такой подход удобен, когда результат нужно использовать в других частях программы.

Вложенные вызовы:

console.log(multiplyByTwo(3)); // напрямую печатаем результат

Функции без return:

Если функция ничего не возвращает, она просто выполняет действие:

function greet(name) {
  console.log("Привет, " + name + "!");
}

Такие функции называют "процедурными", они просто что-то делают.

ex04 – My Moving Box

В этой задаче мы работаем с DOM — это структура HTML-документа, которую можно менять с помощью JavaScript.

Каждый элемент на странице можно "поймать" по его id:

let my_box = document.getElementById("my_box");

Как изменить стили:

У объекта my_box есть свойство style, через которое можно менять CSS:

my_box.style.bottom = "0px";
my_box.style.right = "0px";

Таким образом можно "переместить" элемент в нужную часть окна браузера.

position: absolute

Чтобы элемент можно было перемещать с помощью top, left, right, bottom — в CSS он должен иметь position: absolute:

#my_box {
  position: absolute;
  width: 100px;
  height: 100px;
  background-color: red;
}

Теперь ты можешь перемещать элемент по экрану:

  • my_box.style.top = "100px";
  • my_box.style.left = "50px";
  • my_box.style.bottom = "0px";
  • my_box.style.right = "0px";

Пример перемещения:

<div id="my_box" style="position:absolute; width:100px; height:100px; background:red;"></div>
<button onclick="moveBox()">Переместить</button>

<script>
function moveBox() {
  let my_box = document.getElementById("my_box");
  my_box.style.bottom = "0px";
  my_box.style.right = "0px";
}
</script>

Итоги

  • return — возвращает значение из функции
  • Функции с return можно использовать как "вычисления"
  • DOM — объектная модель HTML-страницы
  • getElementById() — позволяет найти элемент по id
  • .style — позволяет менять внешний вид (цвет, положение)
  • position: absolute — даёт возможность перемещать элемент по координатам
