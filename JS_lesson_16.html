JS_lesson_16: Основы строк в JavaScript (подготовка к Quest06)

Что такое строка (string)?

Строка — это текст. В JavaScript строка — это последовательность символов, заключённых в кавычки.

  • 'одинарные кавычки'
  • "двойные кавычки"
  • `обратные кавычки` (для шаблонных строк)

Примеры:

let s1 = 'hello';
let s2 = "world";
let s3 = `template`;

Как обращаться к символам строки?

Каждый символ в строке имеет индекс (позицию), начиная с 0:

let word = "JavaScript";
console.log(word[0]); // J
console.log(word[4]); // S
console.log(word.charAt(2)); // v

Как узнать длину строки?

Свойство .length возвращает количество символов в строке:

let name = "Elmar";
console.log(name.length); // 5

Как перебирать строку по символам?

Цикл for:

let text = "code";
for (let i = 0; i < text.length; i++) {
  console.log(text[i]);
}

Цикл while:

let i = 0;
while (i < text.length) {
  console.log(text[i]);
  i++;
}

Как сравнивать символы?

Можно использовать условие if и оператор сравнения ===:

let msg = "banana";
for (let i = 0; i < msg.length; i++) {
  if (msg[i] === 'a') {
    console.log("Найдена буква a на позиции " + i);
  }
}

Разница между символом и строкой

В JavaScript символ — это строка длиной 1.

  • 'a' — строка из одного символа
  • "abc" — строка из трёх символов

Они оба являются строками:

console.log(typeof 'a');     // string
console.log(typeof "hello"); // string

Дополнительно: строка как массив символов

Ты можешь думать о строке как об массиве символов. Она индексируется так же, как массив.

let lang = "js";
console.log(lang[1]); // s

Итоги

  • Строка — это текст, заключённый в кавычки
  • Индексация начинается с 0
  • Свойство .length показывает длину строки
  • Циклы помогают проходиться по каждому символу
  • if (str[i] === 'a') — проверка символов
  • Строка может быть длиной 1 или более
