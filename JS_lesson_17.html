JS_lesson_17: Основы массивов в JavaScript

Что такое массив?

Массив (array) — это упорядоченный список значений. Каждый элемент массива имеет индекс (позицию), начиная с 0.

Как создать массив:

let letters = ["a", "b", "c"];
let numbers = [1, 2, 3, 4, 5];

Как получить доступ к элементам массива?

let fruits = ["apple", "banana", "cherry"];
console.log(fruits[0]); // apple
console.log(fruits[2]); // cherry

Индексация начинается с нуля!

Как узнать длину массива?

Используется свойство .length:

let animals = ["dog", "cat", "lion"];
console.log(animals.length); // 3

Как перебрать массив?

Цикл for:

let arr = [10, 20, 30];
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}

Цикл while:

let i = 0;
while (i < arr.length) {
  console.log(arr[i]);
  i++;
}

Цикл for...of (дополнительно):

for (let item of arr) {
  console.log(item);
}

Основные методы массивов (базово)

push()

Добавляет элемент в конец массива:

let colors = ["red", "blue"];
colors.push("green"); // ["red", "blue", "green"]

pop()

Удаляет последний элемент массива:

colors.pop(); // ["red", "blue"]

indexOf()

Находит индекс элемента:

let idx = colors.indexOf("blue"); // 1

join()

Объединяет все элементы массива в строку:

let str = colors.join(", "); // "red, blue"

Тип данных массива

console.log(typeof [1, 2, 3]); // object (особенность JavaScript)
Array.isArray([1, 2, 3]);      // true — лучший способ проверить

Итоги

  • Массив — список значений
  • Индексация с нуля
  • .length — количество элементов
  • Перебор: for, while, for...of
  • Методы: push(), pop(), indexOf(), join()
  • Array.isArray() — проверка, что это массив
