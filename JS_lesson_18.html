JS_lesson_18: Циклы в JavaScript

Зачем нужны циклы?

Циклы позволяют повторять действия много раз. Особенно удобно использовать их при работе со строками, массивами и числами.

Цикл for

Самый популярный цикл — со счётчиком:

for (let i = 0; i < 5; i++) {
  console.log("i =", i);
}
  • let i = 0 — старт цикла (начальное значение)
  • i < 5 — условие (цикл работает, пока оно true)
  • i++ — увеличение счётчика на 1

Пример с массивом:

let arr = ["a", "b", "c"];
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}

Цикл while

Цикл while выполняется пока условие истинно:

let i = 0;
while (i < 3) {
  console.log("Число:", i);
  i++;
}

Прерывание цикла: break и return

break

Останавливает цикл полностью:

for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i);
}

return

Прерывает выполнение функции, в том числе и цикл внутри неё:

function findX(arr) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === "x") return i;
  }
  return -1;
}

Использование цикла для поиска элемента

let animals = ["cat", "dog", "parrot"];
for (let i = 0; i < animals.length; i++) {
  if (animals[i] === "dog") {
    console.log("Нашли собаку на позиции", i);
  }
}

Вывод каждого элемента

Простой цикл для вывода значений:

let nums = [2, 4, 6, 8];
for (let i = 0; i < nums.length; i++) {
  console.log(nums[i]);
}

Подсчёт количества

Например, считаем сколько букв "a" в слове:

let word = "banana";
let count = 0;

for (let i = 0; i < word.length; i++) {
  if (word[i] === "a") {
    count++;
  }
}
console.log("Количество 'a':", count);

Итоги

  • for — цикл со счётчиком
  • while — цикл с условием
  • i++ — увеличение значения на 1
  • break — прерывает цикл
  • return — прерывает функцию и возвращает значение
  • Циклы используются для поиска, вывода, подсчёта
