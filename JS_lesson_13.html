JS_lesson_13: Функция сложения (My Add)

Цель урока

Научиться создавать функцию, которая принимает два числа, складывает их и возвращает результат.

Что такое функция с параметрами?

Функция — это мини-программа, которую мы можем запускать. У неё могут быть параметры — это как входные данные.

Пример:

function greet(name) {
  console.log("Привет, " + name + "!");
}
greet("Elmar"); // Привет, Elmar!

Сложение двух чисел

В JavaScript знак + используется для сложения чисел:

let sum = 5 + 3;
console.log(sum); // 8

Ты можешь складывать:

  • Число + число → 4 + 6 = 10
  • Переменная + переменная → a + b

Создание функции my_add

Функция будет принимать два числа и возвращать их сумму.

function my_add(a, b) {
  return a + b;
}

Теперь мы можем использовать функцию и видеть результат:

console.log(my_add(2, 3)); // 5
console.log(my_add(10, -4)); // 6

Что делает return?

return — это команда, которая возвращает результат из функции обратно в программу.

  • Она завершает выполнение функции
  • Она передаёт результат, который можно сохранить или напечатать

Пример:

let result = my_add(4, 7); // result = 11
console.log(result);

Дополнительные темы

Тип данных: число (integer)

  • let x = 5; — целое число
  • typeof x даст "number"

Валидация (проверка):

Можно добавить проверку, что переданы именно числа:

function my_add(a, b) {
  if (typeof a !== "number" || typeof b !== "number") {
    return "Ошибка: нужны числа";
  }
  return a + b;
}

Отладка с console.log:

function my_add(a, b) {
  console.log("a =", a, ", b =", b);
  return a + b;
}

Итоги

  • Функции могут принимать параметры (входные данные)
  • Знак + складывает два числа
  • return — возвращает результат
  • Можно вызывать функцию с разными значениями
  • Можно проверять тип данных, используя typeof
