JS_lesson_9: Первая функция в JavaScript

Что такое функция?

Функция — это блок кода, который можно выполнить несколько раз. Она помогает не повторять одно и то же, делает код компактным и читаемым.

Функции можно сравнить с "мини-программами внутри программы".

Как объявить функцию:

function имя_функции() {
  // тело функции — действия, которые нужно выполнить
}

Как вызвать функцию:

имя_функции(); // запуск функции

Пример:

function printMessage() {
  console.log("Hello from function!");
}

printMessage(); // выведет текст

Где использовать функции

Функции — это основа любой программы. Они:

  • Позволяют повторно использовать код
  • Разделяют программу на логические блоки
  • Делают код читаемым и понятным

Каждая функция должна выполнять одну задачу. Например:

  • printGreeting() — вывод приветствия
  • calculateAge() — подсчёт возраста
  • logError() — логирование ошибок

Лучшие практики:

  • Названия функций — пиши понятно: printMessage, а не x
  • Отступы — используй отступы для читаемости кода
  • Комментарии — поясняй, что делает код
// Эта функция печатает приветствие
function printGreeting() {
  console.log("Добро пожаловать!");
}

Что важно знать дополнительно

let и const:

Всегда объявляй переменные с let или const, например:

let name = "Elmar";
const PI = 3.14;

Комментарии:

Комментарии помогают понимать код. Они не влияют на выполнение.

// Это однострочный комментарий

/*
  Это многострочный комментарий
  удобно для пояснений
*/

console.log:

Выводит текст в терминал или консоль браузера. Полезно для отладки:

console.log("Значение переменной:", name);

Ошибки и отладка:

Ошибки часто происходят из-за:

  • Отсутствующих скобок { } или круглых скобок ()
  • Забытых точек с запятой ; (не обязательно, но желательно)
  • Опечаток в названиях

Работа в терминале:

  • Файл должен быть сохранён как .js
  • Запуск через терминал: node имя_файла.js

Пример целиком:

function myFirstFunction() {
  console.log("Hello from my first function!");
}

myFirstFunction();

Итоги

  • Функция — это способ переиспользовать код
  • Создаётся через function, вызывается по имени
  • Хорошее имя и структура — залог читаемого кода
  • console.log() — помогает видеть, что происходит
  • Пиши чистый, аккуратный код — с отступами и комментариями
