JS_lesson_2: Debugging и console.log

1. Что такое отладка (debugging)?

Отладка — это поиск и исправление ошибок в коде. console.log() помогает видеть, что происходит внутри программы.

2. Что такое console.log()?

Это команда, которая показывает сообщения в консоли браузера. Она используется для:

  • Проверки значений
  • Понимания хода работы кода
  • Поиска ошибок
console.log("My first print");

3. Пример HTML-файла

<!DOCTYPE html>
<html>
  <head>
    <title>ex04 – Debugging</title>
  </head>
  <body>
    <h1>Открой консоль, чтобы увидеть сообщение!</h1>
    <script>
      console.log("My first print");
    </script>
  </body>
</html>

4. Как открыть консоль в браузере?

  • Открой HTML-файл в браузере
  • Нажми клавишу F12
  • Перейди во вкладку Console
  • Увидишь сообщение: My first print

5. Что можно выводить с помощью console.log()?

Можно выводить текст, числа, переменные и вычисления:

console.log("Привет");
let age = 20;
console.log(age);
console.log("Возраст: " + age);
console.log(5 + 3); // 8

6. Зачем это нужно?

Без console.log() ты не знаешь, что происходит в программе. Он — твой помощник и "глаза" внутри кода.

7. Заключение

  • console.log() — выводит сообщения в консоль
  • Помогает видеть, как работает код
  • Очень полезен при обучении и поиске ошибок
  • Открывай консоль через F12 → Console
