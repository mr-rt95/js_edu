JS_lesson_5: Цикл while и инкремент

Что такое цикл while?

Цикл — это инструмент в программировании, который позволяет повторять одни и те же действия несколько раз.

Цикл while проверяет условие и выполняет блок кода, пока это условие — правда (true).

Общая форма цикла while:

while (условие) {
  // код, который будет повторяться
}

Пример:

let index = 0;
while (index < 5) {
  console.log("Привет!");
  index++;
}

Этот код напечатает "Привет!" 5 раз, потому что условие index < 5 остаётся верным, пока index не станет 5.

Что такое инкремент?

Инкремент — это увеличение переменной на 1. Обозначается ++.

let i = 0;
i++; // теперь i равно 1

Также существует декремент — уменьшение на 1: --

let j = 5;
j--; // теперь j равно 4

Ты можешь использовать и другие способы изменения значений:

  • x += 2; — прибавить 2
  • x -= 3; — вычесть 3
  • x *= 2; — умножить
  • x /= 2; — поделить

Как избежать бесконечного цикла?

Если ты забудешь изменить переменную внутри цикла, он может повторяться бесконечно и "зависнет".

let index = 0;
while (index < 10) {
  console.log(index);
  // НЕТ index++ — цикл будет вечным!
}

Решение: всегда убедись, что переменная меняется, чтобы условие в какой-то момент стало ложным (false).

Другие важные моменты

Можно использовать условие true:

let count = 0;
while (true) {
  console.log("Цикл идёт...");
  count++;
  if (count === 3) break; // остановка с помощью break
}

Команда break

Позволяет прервать цикл в любом месте, даже если условие всё ещё true.

Команда continue

Пропускает одну итерацию цикла и переходит к следующей.

let i = 0;
while (i < 5) {
  i++;
  if (i === 3) continue;
  console.log(i); // не выведет 3
}

Итоги

  • while — цикл, выполняющий код, пока условие true
  • index++ — инкремент (увеличение значения на 1)
  • break — остановка цикла
  • continue — пропуск итерации
  • Следи за условием, чтобы избежать бесконечных циклов
