JS_lesson_19: Функции в JavaScript

Что такое функция?

Функция — это блок кода, который можно вызывать по имени. Она может выполнять действия и возвращать результат.

Как объявить функцию?

function имя(параметры) {
  // действия
}

Пример:

function greet(name) {
  console.log("Привет, " + name + "!");
}
greet("Elmar"); // Привет, Elmar!

Как передавать параметры

Параметры — это переменные, передаваемые в функцию при вызове. Их можно использовать внутри функции.

function square(x) {
  return x * x;
}
console.log(square(5)); // 25

Разница между return и console.log()

return:

  • Завершает выполнение функции
  • Возвращает значение наружу
  • Можно сохранить результат в переменную
function add(a, b) {
  return a + b;
}
let sum = add(2, 3); // sum = 5

console.log():

  • Выводит информацию в терминал или консоль
  • Не возвращает значение
function printSum(a, b) {
  console.log(a + b);
}
printSum(2, 3); // выводит 5

Область видимости переменных

Переменные, объявленные внутри функции, не видны снаружи — они "локальные".

function testScope() {
  let message = "внутри функции";
  console.log(message);
}
testScope();
// console.log(message); // Ошибка! message не видна тут

Аргументы vs Параметры

  • Параметры — переменные, указанные при объявлении функции: function hello(name)
  • Аргументы — значения, которые ты передаёшь при вызове: hello("Elmar")

Итоги

  • function — ключевое слово для создания функции
  • return — возвращает результат
  • console.log() — выводит на экран
  • Параметры внутри объявления, аргументы при вызове
  • Локальные переменные видны только внутри функции
