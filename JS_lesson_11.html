JS_lesson_11: Проверка, является ли число отрицательным

Что такое функция?

Функция — это блок кода, который можно выполнить несколько раз с разными значениями. Она помогает структурировать программу и избежать повторения.

function имя(параметр) {
  // действия
}

Пример:

function sayHello(name) {
  console.log("Hello, " + name);
}
sayHello("Elmar"); // вывод: Hello, Elmar

Как передавать параметры?

Параметры — это переменные, значения которых передаются функции при её вызове. Они делают функции гибкими.

function double(x) {
  return x * 2;
}
console.log(double(4)); // 8

Что такое отрицательные числа?

Число меньше нуля считается отрицательным. Например: -1, -5, -100. Ноль и положительные — это 0 и выше.

Примеры:

-1, -10, -3 — отрицательные
0, 1, 2 — не отрицательные

Операторы сравнения:

  • < — меньше
  • > — больше
  • <= — меньше или равно
  • >= — больше или равно
  • == — равно
  • != — не равно

Как использовать if/else:

if (условие) {
  // выполняется, если условие истинно (true)
} else {
  // выполняется, если условие ложно (false)
}

Пример:

let number = -3;

if (number < 0) {
  console.log("Число отрицательное");
} else {
  console.log("Число неотрицательное");
}

Как использовать return

Ключевое слово return завершает выполнение функции и возвращает результат наружу.

function my_is_negative(n) {
  if (n < 0) {
    return 0;
  } else {
    return 1;
  }
}

Примеры вызова функции:

console.log(my_is_negative(-5)); // 0
console.log(my_is_negative(0));  // 1
console.log(my_is_negative(10)); // 1

Итоги

  • Функция выполняет действия и может возвращать результат
  • if/else проверяет условия
  • return завершает функцию и отдаёт значение
  • Отрицательные числа — это любые числа меньше нуля
  • <, > и другие сравнения нужны для проверки
