JS_lesson_14: Функция вычитания (My Sub)

Цель урока

Научиться создавать функцию, которая принимает два числа и возвращает разность между ними (то есть результат вычитания).

Оператор вычитания -

Знак - используется для вычитания одного числа из другого:

let result = 10 - 3; // 7

Порядок важен!

В отличие от сложения, в вычитании важен порядок операндов:

  • 10 - 3 = 7
  • 3 - 10 = -7

Создание функции my_sub

Функция будет принимать два параметра и возвращать результат param_1 - param_2.

function my_sub(a, b) {
  return a - b;
}

Примеры вызова:

console.log(my_sub(10, 5));  // 5
console.log(my_sub(5, 10));  // -5
console.log(my_sub(3, 3));   // 0

Что такое параметры функции?

Параметры — это значения, которые передаются внутрь функции при её вызове. Они работают как переменные.

function greet(name) {
  console.log("Привет, " + name);
}
greet("Elmar");

Ключевое слово return

Оно позволяет вернуть результат из функции наружу. Без return функция ничего не отдаёт.

Проверка на типы (дополнительно)

Можно добавить проверку, что оба аргумента — числа:

function my_sub(a, b) {
  if (typeof a !== "number" || typeof b !== "number") {
    return "Ошибка: введите два числа";
  }
  return a - b;
}

Итоги

  • - — оператор вычитания
  • Порядок имеет значение — a - b не то же самое, что b - a
  • Функция может возвращать результат через return
  • Можно использовать console.log() для проверки результата
  • Внимание к типам данных — полезная привычка
