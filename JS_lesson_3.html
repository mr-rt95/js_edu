JS_lesson_3: Переменные, строки, инкремент и декремент

ex00 – Variable Char

Переменная — это "коробка" с именем, где можно хранить информацию.

Character — это одиночный символ, например: 'a', 'Z', '%'.

Создание переменной типа char:

let letter = 'c';

ex01 – Variable String

String — это строка, то есть текст из символов.

Примеры строк:

let name = "Elmar";
let sentence = 'Learning is growing';

Можно использовать как одинарные, так и двойные кавычки. Но открывающая и закрывающая кавычка должны быть одинаковыми.

ex02 – Multiple Variable Type

Можно создать переменные разных типов:

  • let age = 34; — целое число
  • let my_name = 'Luke'; — символы (строка)
  • let my_comma = ','; — одиночный символ

Объединять строки можно через +:

console.log('Hello ' + my_name + my_comma + " I'm " + age + ' years old.');

ex03 – First Incrementation

Инкремент (++) — увеличивает число на 1.

Декремент (--) — уменьшает число на 1.

let my_index = 0;
my_index++; // теперь 1
my_index--; // теперь снова 0

Другие формы увеличения и уменьшения:

  • x += 2; — прибавить 2 (увеличение на 2)
  • x -= 3; — вычесть 3 (уменьшение на 3)
  • x *= 5; — умножить на 5
  • x /= 2; — разделить на 2

Пример:

let x = 10;
x += 5; // x = 15
x *= 2; // x = 30
x--;    // x = 29

Итоги

  • char — символ, например 'a'
  • string — строка, например "Привет"
  • + — объединение строк
  • ++ и -- — изменение значения на 1
  • +=, -=, *=, /= — короткие формы операций
