JS_lesson_terminal: Терминал, Node.js и первый скрипт

1. Что такое терминал (CLI / Command Line Interface)

Терминал — это окно, где ты можешь писать команды, а компьютер будет их выполнять. Это как "общение" с компьютером с помощью текста.

  • CLI расшифровывается как Command Line Interface
  • Ты можешь создавать, удалять, переименовывать файлы
  • Можешь запускать программы, скрипты, устанавливать пакеты
  • В Windows терминал — это cmd или PowerShell
  • В Git Bash, macOS и Linux — это Bash-терминал

2. Что такое Node.js?

Node.js — это программа, которая позволяет запускать JavaScript-код вне браузера, прямо на компьютере, через терминал.

Обычно JavaScript работает в браузере, но Node позволяет работать с файлами, серверами и логикой прямо на компьютере.

Как установить Node.js:

  • Перейди на https://nodejs.org
  • Скачай версию LTS (Long Term Support)
  • Установи как обычную программу
  • Проверь установку в терминале:
node -v      // покажет версию Node.js
npm -v       // покажет версию менеджера пакетов npm

3. Что такое .js файл?

.js — это расширение для файлов JavaScript. Это обычный текстовый файл, в котором ты пишешь код.

Пример содержимого файла:

console.log("Hello World!");

Файл должен быть сохранён с расширением .js, например:

  • my_script.js
  • hello.js

Ты можешь создать файл:

  • В любом текстовом редакторе: VS Code, Notepad++, Sublime Text
  • Или через терминал: touch my_script.js

4. Как запустить JavaScript-файл через Node.js

После установки Node.js ты можешь запускать скрипты через терминал.

node имя_файла.js

Пример:

node my_first_script.js

Если внутри файла написано:

console.log("Hello World!");

Ты увидишь в терминале:

Hello World!

5. ex00 — My First Script

Задача:

Создай файл my_first_script.js, напиши в нём:

console.log("Hello World!");

Сохрани файл. Запусти его через команду:

node my_first_script.js

В результате ты увидишь сообщение в терминале. Поздравляю! Ты только что выполнил свой первый JS-скрипт вне браузера.

6. Дополнительные темы

  • console.log() — вывод текста или переменных
  • console.error() — вывод ошибок
  • clear — очистка терминала
  • ls (или dir) — просмотр файлов в текущей папке
  • cd — переход в другую папку
  • touch или echo — создание файла из терминала

Итоги

  • Терминал — текстовая среда для управления файлами и программами
  • Node.js запускает JavaScript вне браузера
  • .js — это JavaScript-файл
  • console.log() — команда для вывода информации
  • node my_file.js — команда запуска
