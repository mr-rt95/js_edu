JS_lesson_10: Аргументы командной строки, process.argv и массивы

Что такое командная строка (терминал)?

Терминал — это инструмент, позволяющий общаться с компьютером через команды. Ты можешь запускать программы, переходить по папкам, выполнять скрипты.

  • В Windows: cmd, PowerShell, Git Bash
  • На Mac и Linux: Terminal

Для JavaScript используется команда:

node имя_файла.js

Что такое process.argv?

В Node.js переменная process.argv — это массив, в котором хранятся все аргументы, переданные скрипту при запуске.

Пример запуска в терминале:

node my_script.js hello world 123

Тогда process.argv будет содержать:

[
  '/путь/к/node',
  '/путь/к/my_script.js',
  'hello',
  'world',
  '123'
]

Аргументы начинаются с индекса 2, потому что:

  • argv[0] — путь к Node
  • argv[1] — путь к скрипту
  • argv[2] и далее — настоящие аргументы

Как работает массив?

Массив — это список элементов. В JavaScript он выглядит так:

let fruits = ["apple", "banana", "pear"];
console.log(fruits[0]); // apple
console.log(fruits.length); // 3

Массивы индексируются с нуля: первый элемент — это [0].

Как перебрать массив с помощью for

Часто нужно пройтись по массиву и выполнить действия с каждым элементом. Это делается с помощью цикла:

let args = process.argv;

for (let i = 2; i < args.length; i++) {
  console.log(args[i]);
}

Этот цикл начнёт с третьего элемента и выведет все аргументы, переданные скрипту.

Полный пример — ex00: My First Script With Args

// файл: my_first_script_with_args.js

let args = process.argv;

for (let i = 2; i < args.length; i++) {
  console.log(args[i]);
}

Запуск в терминале:

node my_first_script_with_args.js apple banana kiwi

Вывод:

apple
banana
kiwi

Дополнительные темы и полезные советы

Переменные:

  • Объявляй через let или const
  • let a = 5;, const name = "Elmar";

console.log():

Выводит данные в терминал. Ты можешь комбинировать текст и переменные:

let city = "Baku";
console.log("I live in " + city);

Отладка:

  • Проверяй, какие аргументы пришли: console.log(process.argv);
  • Следи за ошибками: скобки, синтаксис, пробелы
  • Убедись, что в цикле i начинается с 2

Итоги

  • process.argv — массив аргументов командной строки
  • Массив начинается с 0, аргументы с 2
  • for — позволяет перебрать все аргументы
  • console.log() — выводит результат в терминал
  • Пиши чистый, читаемый код с let и отступами
